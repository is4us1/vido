# דף קטן על פני הים — דף היומי

לחן: הרב רפאל שוורץ · הולחן לכבוד סיום מסכת חולין.

תוכנה שהופכת את הסרטון של אבא ואת הפלייבק (Suno) לסרט אחד. היא רצה בטלפון, ב-Termux.

## הפעלה (Termux רגיל, לא אובונטו)

```bash
[ -d ~/vido ] || git clone https://github.com/is4us1/vido ~/vido; cd ~/vido && git fetch -q origin ccr-c5c34ea7-tuhopd && git checkout -q -f FETCH_HEAD && bash daf_katan/make.sh
```

התוכנה מוצאת לבד את הסרטון ("אבא סוכות" / `Abba_sukkot`) ואת קובץ ה-mp3. הסרט נשמר ב-`Movies/דף קטן על פני הים.mp4` ומופיע בגלריה.

## מה היא עושה

1. **סולם:** מזהה את התו שאבא שר בפועל (הצליל היסודי, בלי הצלילים העיליים) ומעבירה את הפלייבק לסולם שלו, בדיוק של סנטים. אם הקול שלו זז במהלך השיר, הפלייבק זז איתו.
2. **קצב:** מתאימה את הפלייבק לקצב של אבא. אם הוא שר בקצב יציב, היא מותחת את הפלייבק בקו אחד מדויק. אם הקצב שלו משתנה, היא עוקבת אחריו בשלושה מעברים, מגס לעדין. הכול במעבר רציף אחד, בלי תפרים.
3. **מיקס:** מנקה רעשים מהקול של אבא, מאזנת אותו ומוסיפה הד עדין. הפלייבק יורד מעט מתחת לקול כשהוא שר. בסוף מנרמלת עוצמה ל-‎-14 LUFS.
4. **סרט:** פתיח עם שם השיר על רקע מטושטש מהפריים הראשון, ואחריו הסרטון של אבא עם כתוביות מנוקדות. בסיום מופיעה הקדשה לעילוי נשמת הרב עוזר ב״ר חיים שווארץ זצ״ל.

## אפשרויות

| אפשרות | מה עושה |
|---|---|
| `--music-db=-2` | מחליש את הפלייבק ב-2dB, או מגביר עם ערך חיובי |
| `--no-subs` | בלי כתוביות |
| `--preset=medium` | קידוד איטי יותר, קובץ קטן יותר |
| `VIDEO PLAYBACK` | נתיבים מפורשים לקבצים |
